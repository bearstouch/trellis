Workspace

Organized the way you work

Every project gets a window, every window keeps its own tabs, every tab splits as deep as you need. Close the app and it all comes back, stopped and safe, without replaying a keystroke.

Windows in a sidebar, tabs that tell you things

  • Managed windows live in a left sidebar. Rename and color-label tabs per window.
  • A busy bar shows while a tab is printing, and an Input label appears when a program waits for a password or rings for you.
  • Programs can post desktop notifications (OSC 9, 777 and 99). Click one to jump straight to the pane.

Nested splits, horizontal and vertical

  • Split any pane along either axis and keep going. Ratios are yours to drag.
  • New splits and tabs open in the directory you are already in.
  • Restored workspaces start with every session stopped. Typed input is never replayed.

Shell integration with no dotfile edits

  • zsh, bash and fish report their working directory and each command's exit status.
  • Failed commands are flagged, and ⌘↑ ⌘↓ jump between prompts.
  • On by default. Turn it off in Settings → Sessions.

Terminal

The details you notice at 2am

Built on a vendored SwiftTerm engine with small, recorded patches. PTY I/O runs off the main thread, so the window stays smooth under heavy output.

Ligatures, emoji, CJK

Font ligatures, color emoji, wide characters and combining marks drawn on the cell grid, with every underline style.

Inline images

iTerm2's image protocol, so imgcat, yazi, timg and chafa work as you expect.

Scrollback search

10,000 lines per pane by default, searchable, with smart double-click selection for URLs, paths, hashes and more.

Safe paste review

Multiline pastes and text with control characters are shown first, with the line count and the target pane.

⌘-click links

Open web links, file paths and OSC 8 hyperlinks from the output. Anything that could run code is only revealed in Finder.

Desktop notifications

OSC 9, 777 and kitty's OSC 99, cleaned of control characters and rate-limited per pane.

Automation

Let an agent drive

A local JSON-RPC API covers windows, tabs, panes, sessions, input, output, events, declarative layouts and themes. Use it from the trellis CLI, or turn on the MCP server and hand it to Claude Code or any other MCP client.

  • An owner-only Unix socket. Nothing listens on the network unless you turn MCP on.
  • Scoped, expiring grants created in Settings → Automation. Tokens are never passed as arguments.
  • The MCP server is off by default and uses the same grants.
zsh
# script it with the CLI
❯ t() { trellis "$@" --token-stdin --json < ~/.config/trellis/token; }
❯ t tab create --window Project --title Server
❯ t pane split --pane PANE_UUID --axis x
❯ t layout apply ./project-layout.json \
    --namespace project --expected-revision 12

# or hand it to an agent over MCP
❯ claude mcp add --transport http trellis \
    http://127.0.0.1:7777/mcp \
    --header "Authorization: Bearer trl_…"

SSH

Your hosts, one click away

  • A saved host library in File → Hosts…, plus read-only discovery of your ~/.ssh/config aliases.
  • Connections run through /usr/bin/ssh and never bypass host-key trust.
  • An optional per-host password lives in the macOS Keychain, optionally behind Touch ID, and is given to ssh only at its password prompt.

Appearance

Light, dark, and yours

  • Ten editor-inspired families: Modern, One, Monokai, Solarized, Nord, Dracula, GitHub, Tokyo, Gruvbox and Rose Pine.
  • Separate light and dark slots that follow macOS, with a live preview before you apply.
  • A JSON theme library you can import, edit and share. Bundled Roboto Mono, JetBrains Mono and four more typefaces.

Install

Up and running in a minute

  1. 01

    Download the DMG

    Grab the latest release from GitHub: Universal, Apple silicon only, or Intel only.

  2. 02

    Drag to Applications

    Open the DMG and drag the Trellis icon onto the Applications shortcut beside it.

  3. 03

    Add the CLI, if you want it

    One command creates a single symlink in your home folder. Trellis never edits your shell startup files.

    /Applications/Trellis.app/Contents/Helpers/trellis cli install-link

FAQ

Questions

Is Trellis free?

Yes. Trellis is open source under the MIT license. The code, the issue tracker and every release live on GitHub.

Does it collect any data?

No. There is no telemetry. Terminal output and typed input are never logged or persisted, and secrets stay in the macOS Keychain.

Does it run on Intel Macs?

Yes. The main DMG is Universal 2, and there are smaller Apple silicon and Intel builds on each release. macOS 14 or later is required.

Can an AI agent control Trellis?

Yes, with your permission. Create a scoped grant in Settings → Automation, then use the trellis CLI or enable the MCP server in Settings → Remote Control. Grants expire and can be revoked.

How do I build it from source?

You need Xcode 26 on macOS 14 or later. Clone the repo and run swift build, then swift run Trellis --state-directory "$PWD/.build/dev-state". SwiftTerm is vendored, so it builds offline.

How can I contribute?

Read CONTRIBUTING.md for the workflow, code style and tests, then open an issue or a pull request.
