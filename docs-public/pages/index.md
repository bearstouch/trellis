# Trellis documentation

Trellis is a native terminal for macOS. Each project gets its own space in the left sidebar with renameable tabs and nested splits. Saved SSH hosts, remote workspaces, coding agents, JSON themes and a local automation API with a `trellis` CLI and an optional MCP server are built in.

[Download Trellis](https://github.com/bearstouch/trellis/releases/latest){ .md-button .md-button--primary } [Back to the Trellis site](/trellis/){ .md-button }
