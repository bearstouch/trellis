Automation

trellis CLI

trellis controls the running app from your shell or scripts: create spaces and tabs, split panes, start sessions, apply layouts and switch themes. It's a thin client over the automation API, so it can do only what its grant allows.

Install the command

The CLI ships inside the app at Trellis.app/Contents/Helpers/trellis. To put it on your PATH, link it into ~/.local/bin:

  • Choose Trellis → Install Command Line Tool…, or accept the one-time offer on first launch.
  • Or run it yourself:
$ /Applications/Trellis.app/Contents/Helpers/trellis cli install-link
$ /Applications/Trellis.app/Contents/Helpers/trellis cli install-link --dir ~/bin

Installing creates exactly one symlink. Trellis never edits your shell startup files. After installing from the app, Trellis checks your login shell's PATH and tells you whether trellis is ready, or gives you a line to add yourself.

Note

Move Trellis to Applications first. Installing from the mounted DMG or a translocated copy creates nothing and says so.

The link points into the app bundle, so it keeps working after updates. If you move the app, install the link again. To remove it, run trellis cli remove-link.

Give it a grant

Every command except cli … and help needs a token from a grant you create in Settings → Automation (see Automation API). Pass it in one of two ways:

  • --token-stdin: read the token from standard input, for example from an owner-only file.
  • --keychain-grant GRANT_UUID: read it from the Keychain, where Trellis stored it.

Tokens never go on the command line, where process lists and shell history would see them. The CLI rejects --token, --password and --secret.

Usage

trellis <noun> <verb> [options]
trellis help [<noun> [<verb>]]
trellis --version
  • trellis --help lists the nouns, options and exit codes. trellis <noun> --help and trellis <noun> <verb> --help go deeper. Help needs no running app or token.
  • Options take the form --opt VALUE; --opt=value is rejected.
  • --space, --tab and --host accept a UUID or an exact name.
  • --launch starts Trellis if it isn't running. Without it, a closed app gives APP_NOT_RUNNING.
  • --state-directory DIR targets an instance started with the same flag.
  • Mutating commands accept --idempotency-key KEY. The CLI never retries on its own.
  • The older trellis window … and --window still work as deprecated names for space.

Examples

TOKEN=~/.config/trellis/token   # owner-only file holding the grant token
t() { trellis "$@" --token-stdin --json < "$TOKEN"; }

t space list
t space create --name Project
t tab create --space Project --title Server
t pane split --pane PANE_UUID --axis x
t session start --pane PANE_UUID
t session execute --session SESSION_UUID --command 'git status' --submit
t session output --session SESSION_UUID --view screen
t host connect --host HOST_UUID --space SPACE_UUID
t layout plan ./project-layout.json --namespace project
t layout apply ./project-layout.json --namespace project --expected-revision 12
t theme import ./my-theme.json
t appearance set --mode dark --dark-theme my-midnight

Run trellis <noun> <verb> --help for each command's options. A few rules worth knowing:

  • New panes start stopped. Start them with session start, or pass --start when creating.
  • session execute needs --submit. It succeeds once the command is typed in, even if the command later fails.
  • layout apply needs --expected-revision, taken from layout plan.
  • Closing something with running sessions needs --allow-running, and a grant with session.close. Without it you get CONFIRMATION_REQUIRED and a list of the affected sessions.
  • events subscribe prints one event per line until the connection closes.

Output

By default, success pretty-prints the result and a failure prints trellis: <message> (<code>) to stderr. With --json, stdout always gets one envelope, never colored:

{"ok": true, "result": { … }}
{"ok": false, "error": {"code": "CONFLICT", "message": "…", "exitStatus": 5, "details": { … }}}

Exit codes

0Success: the request was accepted
2Bad arguments, or an invalid layout or theme; also an ambiguous name

4Authentication or permission denied
5Conflict, or confirmation required
6A process failed to launch
7App not running, or the connection failed
8Any other error

Uninstall

trellis cli uninstall-plan lists everything that belongs to Trellis without deleting anything. See Privacy & data.
