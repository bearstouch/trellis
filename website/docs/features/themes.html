Features

Themes

A theme colors the whole app: sidebar, tabs, dividers, focus rings and the terminal itself. Pick one of the built-in themes for each appearance, or write your own as a small JSON file.

Appearance mode

In Settings → Appearance, choose System, Dark or Light. Dark is the default on first launch. System follows macOS; Dark and Light stay fixed.

You pick a theme separately for the dark and the light appearance, so a custom dark theme can sit beside the built-in light one. Switching updates every pane at once, without restarting shells or losing their contents.

Built-in themes

Trellis Dark and Trellis Light are the defaults. Ten more families come with a dark and a light variant each:

  • Modern, One, Monokai, Solarized, Nord
  • Dracula, GitHub, Tokyo, Gruvbox, Rose Pine

These are Trellis adaptations with complete app and terminal palettes. Light variants use a light terminal and dark variants a dark one.

Terminal font

The font isn't part of a theme. Choose it in Settings → Appearance → Terminal font, then choose Apply Appearance. JetBrains Mono is the default. Roboto Mono, Cascadia Mono NF, IBM Plex Mono, Iosevka Fixed and Atkinson Hyperlegible Mono are bundled too, and any monospace font installed on your Mac is listed.

Background opacity and blur

Settings → Appearance → Background opacity (30–100%, default 100%) lets the desktop show through the window. Blur behind background, on by default, frosts what shows through.

  • Terminal backgrounds take the opacity as set. The sidebar, tab bar, headers and status bar never go below 60%, so their labels stay readable.
  • Text, the cursor, selections, sheets, the command palette and the find bar stay opaque.
  • The window stays opaque while macOS Reduce Transparency or Increase Contrast is on.

Create a theme

  1. Start from a copy of the dark or light example.
  2. Change id, name and any colors you want.
  3. Open Settings → Themes → Preview JSON… and choose your file.
  4. Choose Preview in Workspace to try it on your real panes. Cancel Preview puts everything back.
  5. Choose Save & Use Theme to install and activate it.

Only version, id, name and appearance are required. Every color you leave out comes from the built-in theme for that appearance, so a minimal theme is short:

{
  "version": 1,
  "id": "my-midnight",
  "name": "My Midnight",
  "appearance": "dark",
  "terminal": { "background": "#101820", "foreground": "#E8EEF4" },
  "ui": { "accent": "#7CC7FF" }
}

A fuller theme sets the terminal and app palettes (ANSI list trimmed here):

{
  "version": 1,
  "id": "my-dark",
  "name": "My Dark",
  "appearance": "dark",
  "terminal": {
    "background": "#141820",
    "foreground": "#E8EEF4",
    "cursor": "#B9DCFF",
    "cursorText": "#141820",
    "selectionBackground": "#3F6AA1",
    "selectionForeground": "#FFFFFF",
    "ansi": ["#1B202A", "#EF8585", "#8DDAA4", "#F2CC7A", …16 colors in all]
  },
  "ui": {
    "background": "#141820",
    "surface": "#202735",
    "sidebarBackground": "#10141B",
    "foreground": "#E8EEF4",
    "mutedForeground": "#B0BAC9",
    "accent": "#8BC7FF",
    "border": "#66758B",
    "activeTabBackground": "#354C6A",
    "activeTabForeground": "#FFFFFF",
    "focusRing": "#8BC7FF",
    "success": "#8DDAA4",
    "warning": "#F2CC7A",
    "error": "#FFA4A4"
  }
}

Previewing never installs anything and never touches running sessions. Leaving Themes or closing Settings cancels a preview.

Format rules

  • UTF-8 JSON, at most 64 KiB. version is 1.
  • id: lowercase, up to 64 characters. The trellis- prefix is reserved for built-in themes. name: up to 100 characters.
  • appearance: dark or light. It picks the fallback colors and the slot the theme can be used in.
  • Colors are opaque #RRGGBB. Alpha isn't supported.
  • ansi is optional, but if present it must list exactly 16 colors: black, red, green, yellow, blue, magenta, cyan, white, then the bright versions.
  • Unknown fields, duplicate keys and invalid colors are errors. The message names the field, and nothing is installed.

Themes are data only: no includes, fonts, images or scripts.

Contrast warnings

The preview shows text, muted labels, selection, cursor text and status colors, and warns about low-contrast pairs by field name. Warnings are advice; you can still save the theme.

Light terminals

On a light terminal, Trellis adjusts 256-color output to your theme and lifts nearly invisible text to a readable contrast, so prompts designed for dark terminals don't draw as black blocks. 24-bit colors are never changed.

Manage your themes

  • Custom themes are stored in the Themes folder of your Trellis data folder. Importing copies the file, so you can delete the original.
  • Open Themes Folder lets you edit themes in any editor. Reload Themes picks up the changes without a restart. An invalid file keeps its last valid colors and shows the errors.
  • Installing a theme with an ID that already exists asks you to Replace Theme.
  • Export… writes the theme as you wrote it. Export Resolved… also includes the inherited colors, for an exact copy on another Mac.
  • Delete Theme removes it. If it was selected, Trellis falls back to the built-in theme for that slot.

Themes apply to the whole app. Scripts with the right permission can import and select themes through the trellis CLI.
