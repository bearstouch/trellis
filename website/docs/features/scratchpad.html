Features

Scratchpad

Write a command or script beside your panes, check its syntax and run it in the focused pane. When it works, save it as a task in the project's launch.json.

Open the scratchpad

Click the </> icon in the dock, choose View → Show Scratchpad, or press ⌥⌘E. The editor gets keyboard focus; press ⌥⌘E again to go back to the terminal.

The scratchpad works with the focused pane, which must be on this Mac. Its icon is dimmed for SSH and remote workspace panes.

The editor

The editor uses the terminal's font and theme colors, with syntax highlighting and line numbers. Smart quotes, dash substitution, text replacement and spell checking are off, so what you type is what runs.

  • Undo, Find (⌘F, ⌘G, ⇧⌘G) and the usual editing commands work. Find searches the editor while it has focus.
  • Tab inserts a tab. ⌃Tab moves focus out of the editor.
  • A buffer holds up to 64 KB.

Check and run

ActionShortcut
Validate (check syntax)⌥⌘V
Run in the focused pane⌘↩
Save as Task⌥⌘S

These work while the editor has focus. The footer also has a Clear (trash) button, and each icon button's tooltip gives its name and shortcut, or why it's disabled.

Validate checks the syntax without running anything. You see Syntax OK, or each problem as Line N: message with the line marked in the gutter. If the interpreter can't be found, you see Not checked, and Run still works.

Run checks first, then types the command into the focused pane and presses Return. The footer's Runs in shows which pane that is and whether it's ready. Run is available only when that pane is a local shell with shell integration, idle at its prompt, with no task running. The script runs in the pane's current folder.

Save as a task

  1. Click Save as Task or press ⌥⌘S.
  2. Enter a task name, a file name (suggested from the task name, such as deploy-preview) and an optional group. The sheet shows the exact command.
  3. Click Save, or Save & Run to run it straight away.

The script is saved to .trellis/scratch/<name>.<ext> in the focused pane's project, and a task is added to .trellis/launch.json:

{ "name": "Deploy preview", "command": "bash .trellis/scratch/deploy-preview.sh" }

A task with the same command isn't added twice, and a taken name gets a number. If the pane isn't in a project, its current folder becomes one, except your home folder or /.

For Markdown, the button is Save File… and saves .trellis/scratch/<name>.md without adding a task.

Open saved scratchpads

The file selector in the header (Scratchpad until you save) lists the files in the project's .trellis/scratch/ folder. Choose one to open it; Edited appears while your buffer differs from the saved file. New Scratchpad starts an empty buffer.

Clear also starts an empty buffer. Both ask first if you have unsaved changes. The saved script and its task are never removed.

Privacy

The buffer lives in memory only: it isn't saved with your workspace and is gone when you quit. Text is written to disk only when you validate (a temporary private file), run (a private copy, deleted when Trellis quits) or save (into your project).

Warning

Saved scripts are ordinary files in your repository. Anyone who can change them changes what the task runs, so review changes to .trellis/scratch/ like any other code.

Known limits

  • The syntax check uses the first interpreter found in the app's PATH, /opt/homebrew/bin, /usr/local/bin, /usr/bin or /bin. That can differ from your shell's, such as macOS's /bin/bash 3.2 versus a newer Homebrew bash.
  • Checks find syntax errors only; a script that parses can still fail.
  • There's one scratchpad buffer, shared by all spaces.
