Features

Terminal

Each pane is a full terminal running your login shell. It handles vim, less, top, colors, mouse reporting and Unicode, and it treats everything a program prints as untrusted.

Sessions

A pane runs your default login shell with real job control: ⌃C interrupts, ⌃D ends input, and resizing works as you'd expect. Pick the shell in Settings → Sessions → Shell.

When a program exits, the pane stays open and shows its exit code. Press Restart to start a fresh session in the same pane.

Copy and paste

  • ⌘C copies the selection. With nothing selected it does nothing; it never sends an interrupt. ⌃C is still the terminal interrupt.
  • ⌘V pastes into the focused pane only.
  • Edit → Copy All Retained Text copies the pane's whole history as plain text. Copied text never contains escape sequences.
  • Double-click selects a whole token: a URL, email address, file path (with an optional :line:column), UUID, IP address, git hash, or a quoted string when you click its quote. Triple-click selects the line.

Paste review

Pasting more than one line, or text with control characters, opens a review first. It shows the line count, any invisible characters and the target pane. Cancel sends nothing. A paste never adds a newline that wasn't in the clipboard.

When your shell supports bracketed paste, Trellis uses it and strips any paste markers hidden in the text, so a paste can't end early and run the rest as commands.

Paste and drop file paths

  • Edit → Paste Escaped Path pastes a copied file path, escaped for your shell.
  • Drag files from Finder onto a pane to insert their paths, in drag order, separated by spaces. The same escaping and review apply. Nothing is run, opened or uploaded.

Clear

Edit → Clear (⌘K, also in the pane's context menu) drops the scrollback and everything above the cursor line, like Terminal's ⌘K. Your prompt and anything you've typed stay. Nothing is sent to the program.

Scrollback and search

Each pane keeps 10,000 lines of scrollback by default (up to a 16 MiB cap); change it in Settings → Sessions. The oldest lines go first.

  1. Press ⌘F to open the find bar in the focused pane.
  2. Type your search. Trellis shows the current match.
  3. Press ⌘G for the next match and ⇧⌘G for the previous one.

Search tells you when older output it could have matched has already been dropped. Full-screen programs (vim, less, top) and the shell's history are searched separately.

With shell integration, ⌘↑ and ⌘↓ jump between prompts.

Links

Hold ⌘ and hover to underline a link; ⌘-click opens it. Links come from programs that print hyperlinks (ls --hyperlink, compilers, rg) or are detected in plain text.

  • Web and mail links open in your default browser or mail app.
  • Local file paths open in the file's default app. A :line:column suffix is ignored.
  • Apps, scripts, installers, disk images and anything executable are shown in Finder instead of opened.
  • Right-click a link or path for Open Link / Copy Link, or Open / Show in Finder / Copy Path. This also works on selected text that names a file.

Output alone never opens anything. Relative paths open only in local panes whose shell reports its folder, and panes connected over SSH never open file paths.

Fonts and text

JetBrains Mono is the default font. Roboto Mono, Cascadia Mono NF, IBM Plex Mono, Iosevka Fixed and Atkinson Hyperlegible Mono are bundled too. Pick one in Settings → Appearance, where you also set:

  • Ligatures (on by default): draws ->, != and similar as joined glyphs in fonts that have them.
  • Bold as bright colors, Use bold fonts, Use italic fonts and Allow blinking text. Blinking stops while Reduce Motion is on.
  • Cursor shape and Blink cursor.
  • Bell: see Notifications.

Use ⌘+, ⌘- and ⌘0 to zoom in, zoom out and return to actual size. Emoji, flags, combining marks and CJK text keep stable widths, so columns line up.

GPU rendering

Turn on Settings → Sessions → GPU rendering (Metal) to draw panes on the GPU. It's off by default. Text looks the same either way; heavy output is faster with Metal, at about 5 MiB of extra memory per pane. If Metal fails, the pane falls back to CPU drawing without losing content.

Inline images

Programs that use iTerm2's inline image protocol, such as imgcat, yazi, timg and chafa -f iterm, can show images in a pane. Images scroll with the text and stay in scrollback.

  • PNG, JPEG, GIF (first frame), BMP, TIFF, WebP and HEIC are supported. PDF and SVG aren't.
  • Very large images are refused or shrunk to fit. Image data never downloads or writes a file.

Output is untrusted

Anything can write to a terminal, so Trellis doesn't let output act for you:

  • Programs can't read or write your clipboard (OSC 52 is off).
  • Links open only on a ⌘-click or a menu choice, and never launch code.
  • Nothing printed can change permissions, including text that looks like instructions to an agent.

Terminal output and what you type are never logged.
