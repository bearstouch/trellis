Features

Directory jump

Trellis remembers the directories your shells have recently and frequently been in. Press ⌘J, type a few letters and press ↩ to go back to one, instead of typing cd again in every new tab.

Jump to a directory

  1. Press ⌘J, or choose View → Jump to Directory…. The command palette opens on Jump to Directory….
  2. Type part of the path. Letters only have to appear in order.
  3. Press ↩.

Directories also show up in the palette's general search, so ⇧⌘P finds them too.

ActionShortcut
cd in the focused pane if its shell is idle, otherwise open a new tab↩
Open in a new tab⌘↩
Open in a split beside the focused pane⌥↩

Trellis types cd only when the pane's shell is at its prompt, clearing any half-typed input first. If something like vim is running, you get a new tab instead and nothing is sent to it. A split isn't possible while a pane is maximized.

This Mac and remote hosts

Directories are remembered per machine, under a heading for each, with the current machine's first. A path is only ever used on its own machine:

  • A directory on this Mac opens in the current space if it's local, otherwise in the first local space, otherwise in a new space.
  • A directory on a host opens a tab in that host's remote workspace, or starts one.
  • From a plain SSH pane, every row opens a new tab, since its paths can't be verified.

If a directory on this Mac no longer exists, Trellis says so and forgets it. If it doesn't answer within 2 seconds (such as a dead network share), nothing opens and the row stays. A missing directory on a host starts the shell in the home folder instead.

How the list fills up

A visit is recorded each time a pane's shell reports a new directory at its prompt. This needs shell integration on zsh, bash or fish; plain SSH panes and shells without integration record nothing. Pressing ↩ at a prompt doesn't count, and neither does reconnecting to a running session.

Rows are ranked by how often and how recently you visited:

Last visitWeight per visit
Under 1 hour4
Under 1 day2
Under 1 week0.5
Older0.25

Trellis keeps up to 100 directories across all machines. Over that, the one visited least recently is dropped.

Directories that are never remembered

  • System and temporary folders, such as /tmp, /private/var, /var/folders, /etc, /proc and /System
  • Anything inside .ssh, .gnupg, .aws, .kube, .password-store or .Trash
  • / and your home folder itself
  • Network locations: /net, /Network, /afs, and on this Mac any network share, including those under /Volumes

Hosts get the path rules only: Trellis can't tell whether a folder on a host is a network mount. A symbolic link that leads into a skipped folder is recorded under its own path.

Turn it off or clear it

History stays on this Mac. It isn't included in diagnostics, in Export Spaces & Hosts, or in the automation API or CLI.

  • Turn off Settings → Sessions → Remember directories to stop recording new visits. Existing rows still work.
  • Click Clear Directory History… in the same section to delete every entry, after a confirmation.

To change the ⌘J shortcut, use Settings → Keyboard. If you had already bound ⌘J to something else, yours is kept and Jump to Directory starts unbound. See Keyboard shortcuts.
