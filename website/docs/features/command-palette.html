Features

Command palette

The command palette is one searchable list of everything Trellis can do and everywhere you can go. Type a few letters to run any action, or jump to a space, tab, pane, saved host, task, theme or recent directory, without remembering its shortcut or menu.

Open the palette

Press ⇧⌘P, or choose View → Command Palette…. Press ⇧⌘P or Esc again, or click outside it, to close it. Keyboard focus goes back to the pane you were in.

While the palette is open, nothing you type reaches a shell, and workspace shortcuts like ⌘D do nothing behind it.

Search

Matching is fuzzy and ignores case: the letters you type only have to appear in order. Matches at the start of a word or in a row rank higher, and items you used recently get a small boost. Results are grouped by kind, with the best match selected.

For example, spl finds Split Left/Right and Split Top/Bottom. Some actions also answer to related words: split finds Maximize / Restore Pane too.

With an empty field, the palette shows up to three items you used recently in this session, then suggestions. Recents and what you type are never saved.

Settings… and the welcome tour are listed too. Statuses such as Running, Stopped or Exited (0) are shown in words.

Scopes

A scope lists one kind of item only. Select a scope row and press Tab or ↩ to enter it; press ⌫ in an empty field to leave it.

  • Go to Space…
  • Go to Tab… lists every tab under its space's name, current space first.
  • Go to Pane…
  • Connect to Host…
  • Run Task…
  • Use Theme…
  • Jump to Directory… (also ⌘J; see Directory jump)

Launch Agent… lists the coding agents for the focused pane.

Preview themes

Moving the selection onto a theme previews it across the workspace. Move on or press Esc and your previous colors come back exactly. Press ↩ to keep it. See Themes.

Note

Saved scratchpads aren't listed in the palette yet. Toggle Scratchpad is, and you can open saved scratchpads from the scratchpad's header.
