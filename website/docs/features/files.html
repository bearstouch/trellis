Features

Files

The Files view shows the focused pane's project as a tree, so you can find a file, open it in your editor or copy its path without leaving the terminal.

Open Files

Click the folder icon at the top of the dock, or press ⌥⌘F. The keyboard goes straight to the search field. Press ⌥⌘F again to hide it.

Files works for panes on this Mac only. Its icon is dimmed for SSH and remote workspace panes.

What it shows

The tree starts at the focused pane's project: the nearest folder at or above the pane's folder that contains .trellis or .git. Outside a project, it shows the pane's folder. A cd in the pane, or focusing another pane, moves the tree.

Folders come first, then files. The tree leaves out:

  • .git, .build, .swiftpm, node_modules, DerivedData and .DS_Store
  • Whatever the project's top-level .gitignore ignores
  • Hidden files, unless you turn on the eye button

Only the top-level .gitignore is read, with its simple patterns. Negations (!), nested .gitignore files and global excludes are ignored.

Use Collapse All to close every folder and Reload to read them again.

Search

Type in Search files… to find files by name anywhere in the project. Letters only have to appear in order, as in the command palette. Include a / to match against the path. The best match is selected; press Esc to clear the search and get the tree back.

Search looks at up to 20,000 files and shows up to 200 results.

You can also double-click a row to open it, use the copy button on a row, or drag a row onto a pane to insert its quoted path, as when dropping from Finder. Inserted paths are quoted for the shell and never run by themselves.

Right-click a row for Open With, Reveal in Finder, Copy Name and Type cd to …, which types cd '<folder>' at the prompt without pressing Return.

Open in your editor

Open in opens the selection, or the project folder when nothing is selected, in the app you chose last (Finder until you pick another). Click the arrow beside it to choose a different app; Trellis remembers it, and Changes uses the same choice.

The menu lists Finder, then whichever of these are installed:

  • Cursor, VS Code (or VS Code Insiders, or VSCodium), Zed
  • Xcode, Sublime Text, Nova
  • IntelliJ IDEA, WebStorm, PyCharm

Then Default App (whatever macOS opens the file with), New Tab Here (a Trellis tab in that folder) and Other App…, which picks any app once without remembering it.

Note

Finder and Default App never run anything. An app, a script or another executable file is revealed in Finder instead of opened.
