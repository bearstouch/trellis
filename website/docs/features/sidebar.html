Features

Right sidebar

Files, changes, the scratchpad, tasks and coding agents share one sidebar on the right of the window. A narrow dock along the window's right edge switches between them, like an editor's activity bar.

The dock

Click an icon to show that view. Click the shown view's icon again to hide the sidebar and return to the terminal. Only one view is shown at a time.

It follows the focused pane

Every view acts on the focused pane and follows focus as it moves:

  • Files shows the pane's project.
  • Changes shows its git repository's uncommitted changes.
  • Scratchpad runs scripts in it.
  • Tasks lists its project's tasks and runs them in it.
  • Agents opens agents in its folder, on its machine.

Pane headers keep only the pane's own tools: machine, maximize, split and close.

When a view is dimmed

Some views only work for panes on this Mac:

Focused paneFiles, Changes, ScratchpadTasks, Agents
Local shell or agentAvailableAvailable
Remote workspace shell or agentDimmedAvailable
SSH (a saved host, or a pane started straight into ssh, mosh or autossh)DimmedDimmed

A dimmed icon can't be clicked; hover it to see why. If you focus a pane the open view doesn't apply to, the sidebar hides, and it comes back when you focus a pane it applies to.

Resize the sidebar

Drag the sidebar's left edge. It's 380 points wide by default and can be 280 to 640. All views share the same width. Showing, hiding and resizing the sidebar never change your saved workspace.
