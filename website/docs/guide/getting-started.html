User guide

Getting started

Install Trellis, take the short tour, and open your first project. It takes a couple of minutes.

Requirements

  • macOS 14 Sonoma or later.
  • An Apple silicon or Intel Mac. There's one Universal 2 app for both.

Install

  1. Download the latest Trellis-<version>.dmg from the releases page.
  2. Open the DMG and drag Trellis into Applications.
  3. Eject the DMG and open Trellis from Applications.

Note

Run Trellis from Applications (or ~/Applications), not from the DMG. The command line tool and updates only install from there.

Trellis is distributed directly, not through the Mac App Store, and isn't sandboxed, so your shells behave exactly as they do in any other terminal. Releases are signed and notarized by Apple.

The welcome tour

The first time Trellis opens, an eight-step tour introduces spaces, tabs and splits, sessions that keep running, projects, remote work, coding agents and keyboard control.

  • Move with Next and Back, the page dots, ← → or ↩. esc or Skip Tour closes it.
  • The last step lets you pick the Appearance (System, Dark or Light), choose whether sessions keep running after you quit, and install the trellis command. Each choice applies right away.
  • Replay it any time from Help → Welcome Tour or the command palette.

First steps

  1. Open a space. Press ⌘N for a new space. It appears in the left sidebar with one tab running your login shell.
  2. Add tabs and splits. ⌘T opens a tab. ⌘D splits the pane left/right and ⇧⌘D splits it top/bottom. Move focus with ⌥⌘ + arrow keys.
  3. Name things. Double-click a tab to rename it. Right-click a tab and choose Color to label it.
  4. Save it as a project. Press ⌘O to open Projects, choose New from Space… to capture the space you just arranged, and launch it again later in one step. See Projects.
  5. Find anything. Press ⇧⌘P for the command palette: every action, space, tab, host, task and theme in one list.

Install the command line tool

The trellis command controls the running app from your shell and from scripts. Installing it is always your choice:

  • Accept the one-time offer on first launch (or on the tour's last step), or
  • Choose Trellis → Install Command Line Tool… at any time.

Trellis creates a single link at ~/.local/bin/trellis and then tells you whether that folder is on your PATH. If it isn't, it shows a line to add to your shell profile. Trellis never edits your dotfiles itself.

$ trellis --help

See trellis CLI.

Updates

Choose Trellis → Check for Updates… to look for a new version. Updates are signed and install in place; Trellis relaunches into the new version.

Automatic daily checks are off until you turn them on in Settings → Updates. You can also opt in to beta versions there.
