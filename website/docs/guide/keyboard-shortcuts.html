Changing shortcuts

  1. Open Settings → Keyboard.
  2. Click an action's shortcut and press the new chord (esc cancels), or click Clear to leave it unbound.
  3. Click Save Shortcuts. Restore Defaults puts every binding back.
  • Every shortcut you set must include ⌘, so ⌃ and ⌥ combinations always reach your shell.
  • Trellis rejects a chord that's already taken before saving it, so a conflict can never silently disable a command.
  • When an update adds a new default that you had already used for something else, your binding wins and the new action starts unbound.
  • Unbound actions are still in their menus and in the command palette.

Option as Meta

Turn on Use Option as Meta key in Settings → Keyboard if you use Emacs-style or readline shortcuts such as ⌥B and ⌥F. It's off by default, so ⌥ types the special characters of your keyboard layout.
