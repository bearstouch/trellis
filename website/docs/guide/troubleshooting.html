Troubleshooting

Common problems and what to do about them. If yours isn't here, open an issue on GitHub.

Sessions

My sessions were gone after a restart

Sessions survive quitting Trellis, closing the window and a crash, but not logging out or restarting your Mac. After a restart, your spaces, tabs and splits come back stopped; press Start Session in a pane to run it again.

Programs are still running after I quit

That's the default: sessions keep running in a background helper. To end them, quit and choose Stop Sessions when asked, or turn on Settings → Sessions → Stop sessions when Trellis quits.

“Stop Them” or “Leave Running” at launch

Trellis found sessions still running that no pane claims, for example after you closed their pane while Trellis was quitting. Stop Them ends them; Leave Running leaves them alone.

Older output is missing after relaunch

A reattached pane replays only its most recent output (up to 4 MiB). Full-screen programs such as vim are asked to redraw. Want output back for panes that were stopped? Turn on Restore scrollback after quit in Settings → Sessions.

Workspace recovery

If your saved workspace file is damaged, Trellis opens a recovery screen instead of overwriting it. Choose Use Backup to load the last good copy, or Start Empty. The damaged file is kept beside it.

A workspace saved by a newer Trellis opens read-only and is never overwritten. Downgrading isn't supported, so copy ~/Library/Application Support/com.bearstouch.trellis/ before you try an older version.

The terminal font changed

If the font you picked was removed or isn't monospaced, Trellis falls back to Menlo or the system monospace font and shows a notice. Choose another font in Settings → Appearance.

trellis: command not found

  • Install it from Trellis → Install Command Line Tool…. It creates ~/.local/bin/trellis.
  • If Trellis says ~/.local/bin isn't on your PATH, add the line it shows to your shell profile and open a new pane.
  • Running Trellis from the DMG? Move it to Applications first; the tool won't install from the DMG.

SSH asks for my saved password again

A saved host's password is answered by the Trellis that started the session. After you quit and relaunch, SSH sessions kept running in the background can no longer use it, so ssh prompts the next time it needs a password. New connections use the saved password as usual.

Dark blocks on a light theme

Programs that send exact 24-bit colors get exactly those colors, so some can still draw dark backgrounds under a light theme. Basic ANSI colors are adjusted to stay readable. Try one of the dark themes for that program, or its own light color scheme.

A file path doesn't open when I ⌘-click it

Relative paths open only where shell integration reports the current directory, so check that it's on in Settings → Sessions and that you're using zsh, bash or fish locally.

Keychain asks for access again

Builds you compile yourself aren't signed by Bearstouch, so macOS may ask again for Keychain access to saved passwords and automation tokens after each rebuild. Released builds don't.

Updates

  • No update is offered: check you're on the version you think with Trellis → About Trellis, then Settings → Updates → Check Now.
  • Installing an update quits Trellis. If you cancel the quit, the install waits. Keep Running leaves your sessions alive through the update.

Starting over

Everything Trellis saves is in ~/Library/Application Support/com.bearstouch.trellis/. Quit Trellis with Stop Sessions, move that folder somewhere safe, and reopen Trellis for a fresh start. Your SSH keys, SSH config and shell history are never in it.

To uninstall cleanly, run trellis cli uninstall-plan to see exactly which files and Keychain items Trellis owns. See Privacy & data.
