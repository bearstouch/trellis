User guide

Settings

Open Settings with ⌘,. Sections are listed on the left. Most changes apply live, without restarting your sessions.

Appearance

The window, terminal text and cursor.

SettingWhat it does
Application appearanceSystem, Dark or Light. Dark is the first-launch default.
Light theme / Dark themeThe palette used in each appearance, for both the app and the terminal. See Themes.
Background opacityMakes terminal backgrounds translucent. Blur behind background blurs what shows through.
Terminal fontJetBrains Mono (13 pt) by default. Roboto Mono, Cascadia Mono NF, IBM Plex Mono, Iosevka Fixed and Atkinson Hyperlegible Mono are bundled too, and any monospaced font on your Mac works. Zoom with ⌘+ / ⌘-; ⌘0 returns to 13 pt.
Cursor, Blink cursorBlock (the default), underline or bar, and whether it blinks.
BellWhat a terminal bell does: a sound (the default), a visual flash, both, or nothing.
LigaturesJoins sequences such as -> and != in fonts that have ligatures. On by default.
Bold as bright colors, Use bold fonts, Use italic fontsHow bold and italic text is drawn. All on by default.
Allow blinking textLets programs make text blink. It stays steady while Reduce Motion is on.

Sessions

How sessions start, draw and keep their output.

SettingWhat it does
ShellYour login shell by default, or another executable. Applies to new local sessions.
Working directoryWhere new local sessions start. Use an absolute path.
Scrollback lines0–50,000 lines per pane (10,000 by default), up to 16 MiB of text. Lowering it drops older output.
Shell integration (zsh, bash, fish)Tracks the directory, commands and prompts without editing your dotfiles. See Shell integration.
Remember directoriesRecords where your shells have been, for Jump to Directory. Clear Directory History… forgets them.
Stop sessions when Trellis quitsOff by default, so sessions keep running after quit. Turn it on to end them when Trellis quits or the window closes. See Sessions keep running.
Restore scrollback after quitShows each pane's last output after relaunch. Saved unencrypted; secrets are removed on a best-effort basis. Off by default.
Workspace disk writesA cap on how much Trellis writes per hour when saving spaces, tabs and settings. Past it, changes are saved together every 5 minutes. ⌘S and Quit always save at once.
Desktop notificationsShows notifications that programs send when you aren't looking at their pane. See Notifications.
Notify when a command finishesWith shell integration, a long command that finishes out of view sends a notification after the time you choose.
GPU rendering (Metal)Draws terminals with Metal, falling back to the CPU if Metal fails. Off by default.

Session Broker

Shows the background helper that keeps sessions running, on this Mac and on each connected remote workspace host: whether it's running, its version and how many sessions it holds. Refresh checks again. Viewing this page never starts or replaces a helper.

Keyboard

Rebind any shortcut, and choose Use Option as Meta key. See Changing shortcuts.

Themes

Browse, preview and manage color themes. Pick an installed theme, preview a JSON theme in the workspace before using it, export, replace or delete your own, and open the themes folder. Cancel Preview always restores exactly what you had. See Themes.

Agents

The coding agents the Agents view launches, and how they report their state.

  • Each agent shows whether it's installed or not found on your PATH.
  • Notify me when an agent needs me or finishes while its pane is out of view.
  • Connect agents typed in a shell: typing an agent's command in a zsh, bash or fish pane runs it with the same status hooks. Your own function or alias of the same name wins.
  • Reveal Agents Folder: add your own agent by dropping a <id>.agent.json file there.

Automation

Manage access for scripts and agents that use the trellis CLI or the automation API. Create a grant with only the capabilities and spaces it needs, copy its token once, and revoke it at any time. See Automation API.

Remote Control

Turn on the MCP server so agents can connect over the Model Context Protocol. It's off by default and listens on 127.0.0.1, port 7777, when on.

Updates

  • Check Now looks for a new version once.
  • Automatically check for updates checks once a day. Off by default. Trellis only downloads the update list; it sends no usage data.
  • Include beta versions offers pre-release builds as well as stable ones.

Development builds have no Updates section.

Where settings live

Settings are saved with your workspace in ~/Library/Application Support/com.bearstouch.trellis/, and a few preferences in macOS's own settings storage. See Privacy & data.
