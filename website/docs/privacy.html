Privacy & data

Trellis has no telemetry and no account. Terminal output and what you type are never logged. Everything it saves stays on your Mac, readable only by your user.

At a glance

  • No telemetry, no analytics. Trellis doesn't report usage, crashes or anything else.
  • One network request of its own: the update check, and only when you start it or turn it on.
  • Output and input stay private. Terminal output and typed input are never logged, and never saved unless you turn on scrollback restore.
  • Secrets live in the Keychain. Automation tokens and saved SSH passwords never go in Trellis's files.
  • No extra permissions. Trellis never asks at launch for Accessibility, Screen Recording or Full Disk Access.

What is saved and where

Trellis keeps its data in ~/Library/Application Support/com.bearstouch.trellis/. Files there are readable only by you (folders 0700, files 0600) and are written atomically, with a backup of the last good version.

FileWhat's in it
workspace.jsonYour spaces, tabs, splits, titles, tab colors and settings
hosts.jsonSaved SSH hosts, and whether each has a saved password (never the password)
projects.jsonYour project library
grants.jsonAutomation grants, with token hashes only
directory-history.jsonUp to 100 recent directories for Directory jump
Themes/Your custom themes
Scrollback/Only if you turn on scrollback restore: each pane's redacted text
control.json, broker.jsonWhere the control socket and session helper are listening. No tokens.
remote-client.json, remote-hosts.jsonA random ID for this Mac's remote sessions and each host's last helper status

A few preferences, such as keyboard shortcuts and the window frame, use the standard macOS preferences store.

Never saved

  • Terminal output and typed input (except opt-in scrollback)
  • Passwords, private keys and other authentication material
  • Environment variable values
  • Process IDs and the arguments of custom processes

Restored panes start stopped, and Trellis never replays anything you typed.

Keychain

Two kinds of secret go in your login Keychain, available only when your Mac is unlocked and never synced to other devices:

  • Trellis Automation: tokens for automation grants.
  • Trellis SSH Host: optional saved SSH passwords, one per host.

SSH keys stay where they are. Trellis stores the path to an identity file, never its contents.

Opt-in scrollback

Settings → Sessions → Restore scrollback after quit is off by default. Turn it on to see each pane's last output after a relaunch.

  • Trellis saves plain text only, after removing likely secrets. Redaction is best effort.
  • Each pane keeps at most its newest 1 MiB, in an owner-only file.
  • The files are not encrypted.
  • They're deleted when the pane closes or restarts, and all of them when you turn the setting off. They're never exported or sent to automation clients.

Directory history

Settings → Sessions → Remember directories keeps a list of where your shells have been, on this Mac only. System, credential and network folders are skipped. Clear Directory History… deletes it.

Network

Trellis makes no network requests of its own except checking for updates:

  • Trellis → Check for Updates… and Settings → Updates → Check Now check once, when you ask.
  • Automatically check for updates is off by default. Turn it on for a daily check.
  • A check is one HTTPS request for the update feed. No identifier, system profile, workspace data or usage data is sent.
  • Updates install only if their signatures verify. Include beta versions opts in to pre-releases.

Everything else is something you start: ssh connections to your hosts, and the MCP server, which is off by default.

On remote hosts

A remote workspace installs a helper in ~/.trellis on the host, with your consent. It opens no network port, and writes no secrets, typed input or terminal output to the host's disk.

Uninstall

  1. Quit Trellis and choose Stop Sessions, so no kept session or helper keeps running.
  2. Run trellis cli uninstall-plan to list every file and Keychain item that belongs to Trellis. It deletes nothing.
  3. Run trellis cli remove-link to remove the command-line link.
  4. Delete Trellis.app.
  5. Delete the folders the plan lists: Application Support, Preferences, Caches and Saved Application State.
  6. Delete the Keychain items in Keychain Access, or with security, repeating until none are left.
$ trellis cli uninstall-plan --json
$ trellis cli remove-link
$ security delete-generic-password -s "Trellis Automation"
$ security delete-generic-password -s "Trellis SSH Host"

Uninstalling never touches ~/.ssh (keys, config, known hosts), your shell startup files or shell history. To remove the helper from a remote host, use Remove Helper… in the host library before you uninstall.
